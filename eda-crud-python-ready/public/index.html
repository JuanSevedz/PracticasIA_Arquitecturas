Qué demuestra

  1. La API actúa como Event Producer.
  2. El Event Broker desacopla productor y consumidor.
  3. UserEventHandler recibe los eventos de forma asíncrona.
  4. El handler realiza la persistencia en MySQL.
  5. La respuesta CUD es 202 Accepted, representando procesamiento asíncrono.
  6. READ consulta MySQL directamente en este prototipo.
