3. Para explicar al profesor

  1. PluginInterface: define init(), execute() y destroy().
  2. PluginManager: carga dinámicamente los plugins y los registra.
  3. Kernel: inicializa los plugins y ofrece execute(plugin, action, payload).
  4. MySQL Plugin: administra el pool de conexiones.
  5. Productos CRUD: contiene la lógica de negocio y solicita SQL al plugin MySQL mediante el Kernel.
  6. Nuevo plugin: se puede agregar mediante la configuración sin modificar el núcleo.
